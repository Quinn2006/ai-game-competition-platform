# v1.0.0 · Windows 手动运行正式版

发布日期：2026-11-15。首个正式源码版本，范围为 Windows 本机部署、用户手动启停和本地加密备份恢复。保留 v0.1.0—v0.3.0 预发布记录。

## 功能

- 账号、个人/团队报名、作品版本管理、管理员审核、比赛分配评委与评分、成绩核查发布和申诉。
- 浏览器分块上传、ZIP 结构与 ClamAV 检查；审核通过后公开发现和隔离试玩；点赞、收藏、评论、有效试玩统计及排行。
- 公告、站内通知、反馈、运营报表导出和可配置的 AI 客服接口。当前不发送业务邮件，AI 需另行配置真实服务。
- 主站、试玩和 ZIP 校验使用独立进程、专用非管理员账号、NTFS 权限、认证命名管道、WFP 网络限制和 Job 资源限制；撤回/下架即时影响后续资源授权。
- 独立生产数据库、最小权限角色与 verify-full TLS；显式批准的初始化/迁移，迁移现为 001—012，新增删除恢复账本。
- 手动 Start/Stop/Backup/Status；关闭入口、排空写入、一致性 AES-GCM 备份、正常停库。取消所有定时开关与开机自动开放要求。
- 独立目标恢复、逐表/逐文件核验、MFA 重加密、旧会话失效及删除账本核对；受控切换与回滚。恢复不会直接覆盖运行中的主库。

## 验证范围

本版本的应用代码基于已验收提交 `5490e71`，发布整理调整版本元数据、文档和迁移集成测试，不修改业务实现。修复旧测试按固定次数回退导致的 CI 失败，改为按迁移编号定位；新增有删除账本时拒绝回退并保留证据的检查。

- 发布回归：147 个 JavaScript 模块语法检查；106 项测试中 104 通过、2 项真实 Windows ACL 测试按默认配置跳过；130 条需求映射与 18 项决策登记检查。基线检查不等于全部需求人工验收。
- 独立空 PostgreSQL 测试库全套集成通过，包括迁移并发、完整空库回退、非空历史保护及删除账本保护；未操作正式库。源码归档在干净解压目录重新安装依赖并通过语法、基线、全部默认测试及 600 次本地 HTTP 冒烟（0 错误）。
- 正式安装历史验收：实际 PostgreSQL TLS/角色隔离、三个 Windows 账号的 ACL/WFP/管道/Job 检查、真实 ClamAV、固定 HTTPS 域名下的管理员登录/MFA、上传审核、匿名试玩和撤销均通过。
- 实际手动 Stop/停机 Backup/Start 和正式备份的独立恢复通过；源库未被恢复操作覆盖。小数据恢复耗时和短时健康采样不作为生产 RTO 或容量承诺。
- 桌面和 390×844 浏览器视口验收通过；手机尺寸模拟不代替真机测试。

详情：[正式安装与验收](https://github.com/Quinn2006/ai-game-competition-platform/blob/v1.0.0/docs/production-installation-2026-11-13.md)、[运行隔离](https://github.com/Quinn2006/ai-game-competition-platform/blob/v1.0.0/docs/production-isolation.md)、[部署与恢复](https://github.com/Quinn2006/ai-game-competition-platform/blob/v1.0.0/docs/production-deployment-recovery.md)。测试报告中的跳过与历史实机验收分别记录，不互相替代。

## 安装与升级

分发为源码 ZIP，不是免依赖 EXE。需要 Windows、Node.js 24+、PostgreSQL 工具和 ClamAV；生产操作使用 PowerShell 7，公网访问另需配置 cloudflared 与两个分离的域名。依赖安装使用 `npm ci --ignore-scripts`。

首次本地试用遵循 [首次安装指南](https://github.com/Quinn2006/ai-game-competition-platform/blob/v1.0.0/docs/first-run.md)。正式安装须先审查部署计划及实际目标，安装器默认路径和域名是本项目现场值，其他机器不能不经调整直接执行。已安装实例不要重复运行 Install。正式环境使用安装目录生成的 Start.ps1、Stop.ps1、Status.ps1、Backup.ps1；`start-local.cmd` 仍用于开发与试运行。

升级前安全停止并验证备份，保留旧代码、配置、数据库、作品和单独的恢复材料。恢复校验要求应用版本、迁移校验和及 PostgreSQL 主版本匹配，不支持跳过版本检查。特别是本机已验收的 0.3.0/001—012 备份，应使用提交 [`5490e71`](https://github.com/Quinn2006/ai-game-competition-platform/tree/5490e71) 的恢复工具；旧 `v0.3.0` 标签尚不含此次生产恢复实现，v1.0.0 工具也会拒绝应用版本不匹配的旧包。先在独立目标验证，再批准切换。

本次源码发布不会自动更新已安装的生产运行程序、迁移生产数据库、重启服务或改变公网路由。

## 已接受的限制

- 本机暂用明确选择的 local-only 备份策略，异盘副本及离线恢复材料备份未验证；同一磁盘损坏可能同时损失数据和备份。默认异盘检查仍保留，不能自动降级为本地备份。
- 上传默认 100,000,000 字节，分块暂存在内存；断线/重启续传、200 MB 上传未实现完整验收。
- 整机重启、长期容量/稳定性、真实移动设备、原游戏存档接入和真实 AI 服务未完成全面验收。本版不宣称高可用、异盘灾备或全部业务场景人工验收完成。
- 运行依赖用户保持电脑、程序和网络可用。备份由手动停止或 Backup 触发，数据损失窗口取决于最后一次成功备份，不承诺固定 RPO/RTO。

源码包不含 data、真实环境配置、密钥、Token、参赛作品、数据库、备份或便携运行时。Release 附件提供源码 ZIP 和 SHA-256 校验文件。
