## 页面、接口及模块

首页 `/`：无轮播、默认最新、八类、五种排序入口（平均时长禁用并说明）、默认每批 12 款可调、完整简介、默认/自定义栅格封面、编辑精选、热门搜索及私人历史。自定义封面只接受最大 500 KB PNG/JPEG/WebP，浏览器等比例适配；数据 URI 在数据库保存，不接收远程追踪地址或 SVG。图片损坏自动回退默认封面。

`/work?id=…` 展示完整简介和操作说明；`/author?id=…`、`/team?id=…` 仅展示公开字段及公开作品；`/rankings` 是总榜/八类分类榜的空状态展示壳，没有伪造赛事排名。

`/catalog/edit?id=…` 为作者资料表单，只有所有者可以保存；`/catalog/admin` 为精选及每批数量/热门屏蔽词设置，需完整管理员会话。正式创作台入口接入待阶段 3 联调。详情仅在游戏服务配置启用时显示独立试玩页链接；详情内嵌试玩组件待阶段 3 联调，不能直接嵌入禁止 frame-ancestors 的 `/play` 页面。

`src/modules/discovery/service.mjs` 管查询与持久化；`http.mjs` 管精确路由、请求体上限、同源、Host、会话与限流。所有用户文本以 textContent 展示；搜索 SQL 参数化，并将 `%`、`_`、反斜杠作为字面值搜索。日志不记录搜索参数、历史或请求体。

GET `/api/discovery/list` 支持 q/category/sort/offset/author/team/featured；其余 GET 为 detail(id)、profile(kind,id)、history、hot、capabilities。POST 为 record(term)、clear、edit、admin。私人接口仅由会话决定账号，忽略 URL 中的账号字段。配置操作和资料编辑写最小审计。

公开查询必须同时满足：当前发布指针匹配作品、版本 approved、未撤销、未撤回、扫描 clean、作者 active、有完整公开资料。草稿/未发布/已撤销作品不会因精选、主页或搜索而泄漏。公开接口逐字段投影；不泄漏邮箱、学号、扫描结果、版本内部元数据或审核状态。
