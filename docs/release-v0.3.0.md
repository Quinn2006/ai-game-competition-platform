# v0.3.0 · 作品分块上传与公网试玩（预发布）

作品从上传、扫描、管理员审核到公开发现和匿名试玩的流程已完成真实公网验收。大包上传改为分块传输，解决本次 26.8 MB 游戏包通过公网单请求上传时出现的网关超时。

## 主要更新

- 创作台补齐公开名称、简介、操作说明与分类；审核通过后自动公开，未通过的版本不向匿名玩家开放。
- 分块上传绑定登录会话，逐块校验权限、顺序及大小；限制临时内存预算，清理过期传输，完整收齐后执行原有扫描流程。页面区分传输、扫描、上传成功和页面更新失败。
- Windows 启动支持本地模式、临时公网隧道和自有 Cloudflare 隧道，提供配置检查及就绪后打开浏览器。
- 提供克隆后的本地初始化入口，已有内置账号不会在重复初始化时重置密码。
- 整理创作台和管理员审核入口，统一导航及校园主题界面，完善赛事、账号与作品管理。
- 增加公告、通知和客服模型配置管理；新增 011 数据库迁移，模型密钥加密存储。
- 加强本地私有存储边界、ACL 检查和就绪检测。

- 本地检查：115 个 JavaScript 模块；74 项测试通过、2 项跳过；130 条需求基线与 18 条决策通过。

- 桌面和 390×844 手机尺寸浏览器进入实际战斗；匿名退出后记录有效试玩。服务重启后作品及发布状态保留。

详细证据见 [上传验收记录](https://github.com/Quinn2006/ai-game-competition-platform/blob/v0.3.0/docs/upload-acceptance-2026-11-09.md)。手机尺寸测试不替代真机验收。

## 使用与升级

运行环境及首次初始化见 [首次运行](https://github.com/Quinn2006/ai-game-competition-platform/blob/v0.3.0/docs/first-run.md)。升级前备份数据库和作品文件，保留现有 `data/`、环境配置和会话密钥。启动入口为根目录 `start-local.cmd`，已有数据库迁移不改写，启动程序应用未执行的迁移。

固定域名配置见 [公网隧道说明](https://github.com/Quinn2006/ai-game-competition-platform/blob/v0.3.0/docs/public-tunnel.md)。在项目根目录运行 `start-local.cmd -Mode Public -TunnelMode Own`；电脑、网站和隧道需持续运行，停止期间公网不可用。

本版本为源码预发布，GitHub 自动提供源码归档；不附带真实数据库、作品 ZIP、Token、密码、备份或运行时。现有公网存在较慢传输和偶发网关错误；长期可用性、容量、真机兼容性、原游戏存档接入、真实 AI 服务及灾备尚未完成全面验收。
