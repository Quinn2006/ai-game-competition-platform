## 本地账号管理

正常启动沿用 `scripts/local-identity-db.ps1` 创建的本机数据库状态与 `scripts/local-identity-run.ps1`。不再要求 `LOCAL_MAIL_PREVIEW=1`，应用不启用 `/dev/mail`。旧的待验证账号在正确密码及适用MFA校验后首次登录转为启用；已禁用、注销中的账号不能借此登录。

在项目根目录执行下列命令，按提示输入对应的本机数据库状态目录。目录中包含忽略入库的 `credentials.json`；新密码通过不回显的输入提示传入子进程标准输入，不写入命令行、日志或文件。

```powershell
$state = Read-Host '本机数据库状态目录的完整路径'
.\scripts\local-account.ps1 -State $state -Action reset-password
# 如需取消尚未到期的注销申请：
.\scripts\local-account.ps1 -State $state -Action cancel-deletion
```

工具只接受回环地址、development环境与匹配数据库标识；成功后撤销旧会话及旧验证/重置凭证，MFA和恢复码不变，并记录身份审计。本机数据库管理员权限即拥有重置能力，不能把该脚本暴露成网络接口。

## AI隐私生命周期

`/support` 提供普通对话查看、主动清空、转正式投诉、投诉结果查询；`/admin` 提供正式投诉处理和结案。

- 普通对话结束后90天删除；主动清空和注销提前删除普通对话。
- 正式投诉复制必要对话与理由，未结案期间保留，结案后按日历一年删除。清空普通对话不抹去依法定产品规则保留的投诉副本，界面明确说明。
- 本地删除与供应商删除队列在同一事务中记录，队列只保存随机请求标识和重试时间，不复制正文；失败5分钟后重试，成功才移除。发送中的对话被清空时不恢复本地内容，完成回调补发远端删除任务。
- AI适配器必须声明不训练、0—90天留存，提供 `answer({requestId,question,knowledge,signal})` 和 `delete({requestId,signal})`。适配器须遵守超时、幂等请求标识和删除语义；这些声明不能替代供应商合同与实测证明。
- 默认无AI适配器，不发送任何对话到外部。未配置时明确提示改用反馈。隐私测试用人工可控替身验证成功、失败及重试，不能证明外部供应商行为。
