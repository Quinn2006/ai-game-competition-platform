第一方 HttpOnly/SameSite 签名游客 Cookie，不使用设备指纹。服务端保存散列身份及30分钟试玩会话；顺序号、会话所属身份/浏览器、当前公开版本、服务端时间均校验。前台连续相邻心跳间隔最多5秒；后台和长缺口不补计时。浏览器桥仅从 isTrusted 输入报告交互。只有正常结束且满足门槛才结算；运行错误、加载失败、失联/崩溃未结束均不计。明确点击“退出试玩”最可靠，关闭标签页的网络请求可能丢失，采用保守漏计。正常结束是实现采用的失效策略，并非已证明的防作弊能力。

每日记录唯一约束、合并事务和聚合增量在同一事务内更新。原始会话/每日明细约30天清理，匿名汇总继续保留；风险记录30天，可由管理员通过 hold API 指定原因与最多30天复查日期，resolve 解除例外；治理事件6个月。赛事尚未接入，不把普通记录冒充赛事留存180天材料。
