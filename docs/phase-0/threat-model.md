# 威胁模型与验证责任

资产：主站会话、学生身份与学号、作品私有包、隔离存档、计分证据、评委身份、管理员权限和备份。攻击者包括游客、恶意参赛作者、被盗账号、越权评委以及失陷供应商。游戏代码与所有客户端消息均不可信。

数据流：浏览器 → 主站业务 API → 私网 PostgreSQL；上传 → 私有隔离存储 → 扫描 → 人工审核 → 不可变公开资源；游戏来源 → 受限消息 → 宿主候选信号 → 服务端核验 → 日去重聚合 → 管理员结果发布。AI 客服只允许答疑数据，不能读取管理查询接口。

|---|---|---|---|
|ZIP 穿越/炸弹/软链/执行文件 → 主机|隔离解压、资源预算、类型/路径双校验、扫描、人工复核|SUP-01 / 3|扫描器未选；不以扫描通过保证安全|
