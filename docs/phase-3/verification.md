## 发现与修复

初次全套测试的回环连接被沙箱拒绝，经正常权限审批运行后通过。初次数据库测试发现迁移 005 未加入显式注册表，已修复并在新的独立实例复验。Host 伪造测试最初使用 fetch，客户端未发送自定义 Host；改用原生 HTTP 请求后验证拒绝。自动审批曾因额度暂时失败，用户要求继续后按原审批流程重试成功。
