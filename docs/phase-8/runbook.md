## 执行入口

从本工作树根目录执行；使用已有 Node.js 24、npm、Git、tar 和已审查的 PostgreSQL 18 本机运行时。不安装新依赖。临时数据库、合成删除账本、备份和日志只写入被忽略的 `tmp/`。该目录不是正式备份库，不得放入真实学生数据。

```powershell
npm test
npm run check
npm run check:baseline
node scripts\ops-local-load.mjs
node scripts\ops-app-rollback.mjs
node scripts\ops-recovery-drill.mjs D:\AI-project\Codex-project1\tmp\phase2-postgres\runtime\pgsql\bin
```

恢复脚本自行创建两个仅回环监听、随机密码的合成实例，完整执行空库迁移回滚、备份、恢复、删除重放和保留记录校验，结束时停止两实例。每次创建新目录，不覆盖旧证据。报告包含 SHA-256 和实际耗时；这些数字不是经批准的 RPO/RTO。合成账本只演示机制，尚不具备生产删除收集、独立存储或权限管理能力。备份摘要只用于记录，生产恢复前必须与独立保存的签名清单校验。

应用回滚脚本将运行时当前 HEAD 归档到独立目录，先启动工作区候选版本，再在同一回环地址启动归档版本，检查存活、账号页面及依赖缺失拒绝就绪。源归档复用本机依赖；正式发布还需不可变依赖和镜像摘要、数据库兼容性及真实流量切换验收。

## 监控与告警

本地启动应用后可另开终端运行，Ctrl+C 停止：

```powershell
node scripts\ops-probe.mjs monitor http://127.0.0.1:4320/health/ready
```

每5秒观测，单次超时3秒；连续3次失败输出 `service.unavailable`，连续2次恢复输出 `service.recovered`，不重复输出未变状态。通知失败下次重试；当前出口仅 stdout，未向任何人发送通知。监控应作为应用之外的独立进程运行，不能仅依赖应用内部定时器。正式接入需确认管理员渠道、值班表、确认/升级时限，并做真实收发演练。初始健康状态是去抖状态，不是首次探测前的健康证明。

生产监控还需收集：请求数、5xx、p95/p99、DB连接/锁等待、磁盘、备份年龄、清理任务心跳、扫描队列、证书到期和进程重启。阈值和告警路由等待 T-11/T-12，不能将本地默认参数当作服务承诺。

## 留存、备份与恢复

权威分类在 `docs/phase-0/data-retention.md`。一般错误30天、安全审计6个日历月、备份滚动30天；法律保留按单条记录暂停，禁止整库无限延期。现有 `identity.cleanup()` 调用有锁和分批上限的审计清理；数据库回归覆盖留存与冻结。未启用身份服务时该定时任务不运行，正式部署必须接通服务并监控任务心跳，不能宣称全站日志自动留存已完成。

运行日志使用白名单字段，不记录原始异常、URL参数、请求体、密码和令牌。stdout 的汇聚、分级保留和到期销毁仍需供应商方案；不得把本地忽略文件当作已自动销毁。

生产设计：管理员配置备份周期，默认每天一次；数据库和对象文件清单/版本一致，独立账号和独立备份存储，加密、最小权限及审计；备份创建后验证摘要和可恢复性；到期删除需遵守保留规则。尚未实现正式定时任务或管理员备份配置界面。

恢复顺序：隔离恢复环境 → 校验备份清单和密钥 → 恢复数据库及对象版本 → 从备份之外的账本重放删除 → 校验注销、公开姓名下线、归档及到期保留 → 重新扫描/校验游戏文件 → 业务回归与就绪检查 → 经批准切换流量。任何删除账本缺失、对象不一致或回归失败均保持隔离。T-11 决定账本最小字段、留存、RPO/RTO和演练频率后才能完成生产方案。

## 发布、回滚和故障处理

发布门禁：集成后的全量自动化和真实扫描通过；管理员实际验收；容量指标获批且混合业务压测达标；恢复/兼容回滚通过；严重/高危安全问题清零；隐私协议与供应商条款确认。任何一项缺失均不发布。

发布先备份并验证，固定源提交及依赖/镜像摘要，在测试环境执行迁移和业务回归，再审批生产部署。现有迁移工具主动拒绝生产变更；本阶段不解除该限制。应用回滚优先切回已验证兼容当前 schema 的稳定产物；有业务数据的 down 迁移会拒绝删除历史，不得强制清表。不可逆变更通过前向修复或隔离恢复处理，必须另行批准。

就绪503：检查脱敏错误码、环境身份和迁移校验和，再检查数据库/私有存储连通；不得把健康接口改成始终200。错误突增：暂停发布，保存脱敏证据，评估应用回滚。备份失败：保留最近已验证备份，调查容量/权限并复验。扫描失败：保持隔离，禁止跳过扫描发布。密钥事故：撤销泄漏凭据并升级；SESSION_SECRET 还用于 TOTP 密钥加密，不能直接更换后假定旧数据可解密。正式密钥轮换/会话撤销方案待实现及演练。

## 容量验证边界

`ops-local-load.mjs` 对存活接口和两条 HTML 路径分别运行200请求、并发10；统计完整响应耗时、错误率和吞吐。探针拒绝外部地址、带凭据/查询参数地址和重定向，限制请求数、并发、响应大小及超时。工具默认只允许回环，不能直接用于生产压测。

T-12 关闭后需在授权测试环境添加真实登录、搜索、上传/扫描、试玩、评论、比赛评分和导出混合负载，覆盖慢启动、峰值、持续运行、资源耗尽和恢复。记录机器规格、预算、并发、p95/p99、业务成功率、CPU/内存/DB/存储指标；30秒游戏加载超时不是性能通过线。
